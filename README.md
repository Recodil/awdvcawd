# Win11 Shell для NixOS

Экспериментальная графическая оболочка для NixOS с интерфейсом в стиле Windows 11. Проект объединяет оконный менеджер niri, оболочку на Quickshell/QML и системные инструменты в одном рабочем окружении.

## Что входит

- Панель задач, меню «Пуск» и управление окнами и рабочими столами.
- Центр параметров, уведомления и быстрые настройки.
- Экран входа и блокировки.
- Центр обновлений, системная диагностика и инструменты восстановления.
- Установщик и конфигурация NixOS.
- Поддержка нескольких языков интерфейса.

## Статус проекта

Проект находится в тестировании. Возможны ошибки, несовместимость с оборудованием и изменения в работе функций. Перед установкой или обновлением сохраните резервную копию важных данных и конфигурации системы. Не рекомендуется использовать проект в критически важных средах без предварительной проверки.

## Сторонние компоненты

Проект включает необязательную интеграцию с `zapret-discord-youtube`. Этот сторонний инструмент изменяет сетевой трафик и может использоваться для обхода фильтрации. Он не предназначен для несанкционированного доступа к чужим системам. Применимость и законность использования зависят от местных правил.
